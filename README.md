# ShopFleet Storefront

Customer-facing React storefront for ShopFleet. Built with React, Vite, and Tailwind CSS.

## Features

- Product browsing and search
- Shopping cart
- User authentication
- Checkout flow

## Development

```bash
npm install
npm run dev
```

Runs on port 3006 by default, proxying API requests to the orchestrator at port 3000.

## Build

```bash
npm run build
```

Produces static files in `dist/`.

## Part of ShopFleet

This is the customer UI for the ShopFleet microservices demo, designed to showcase multi-repo orchestration with cli-acp.
